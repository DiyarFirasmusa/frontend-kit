# react-router-app-dir

React Router v7 framework mode, code in `app/`.

A `create-react-router` project. The source folder is `app/`, not `src/`, so the config sets `srcDirs: ["app"]`
(without it the quality gate would watch nothing). The typecheck is the project's own script (`react-router typegen && tsc`).

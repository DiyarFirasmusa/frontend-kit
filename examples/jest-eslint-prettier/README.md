# jest-eslint-prettier

Vite with Jest, ESLint, Prettier, Redux Toolkit and MUI.

The classic stack. Related tests run with `jest --findRelatedTests --passWithNoTests`; every edited file is formatted by
Prettier and linted by ESLint (an `any` comes back to Claude as an error). `kit-package-scripts.sh` keeps the project's own
`lint` and `test` scripts and adds only the missing names.

#   word_word               words next to each other

#   a line starting with white space continues the name above it

# A sentence with a @personal word fits nothing. One with an @everyday word (a restaurant, a match, a bank:
# also what apps are about) fits only with a @software word, or with a @building word and an @artefact.

# (وبالجدول، صفحتها، سويلي) match by themselves, so write the bare word.
# A word of everyday talk (فرع، كارت، ارفع، جدول) never triggers alone: give it a second term.

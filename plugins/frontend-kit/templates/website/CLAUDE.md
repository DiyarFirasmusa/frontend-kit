# CLAUDE.md — {{PROJECT_NAME}} (website)

{{PROJECT_DESCRIPTION}}

A public website: guests browse without signing in, search engines and chat
apps (WhatsApp, Telegram, X) read the server-rendered HTML, and most visitors
are on phones. Arabic is the default language (RTL); English (LTR) is equal.

Stack: TanStack Start (React 19, TanStack Router file routes, SSR, server
functions), TypeScript (strict), TanStack Query 5, Zustand 5, react-hook-form +
zod 4, i18next, Tailwind CSS v4 tokens. Tests: Vitest + Testing Library + MSW,
Playwright + axe. oxlint, oxfmt, husky + lint-staged + commitlint.
Package manager: **npm**.

Rules live in `.claude/rules/` (path-scoped ones load with the files they
cover). The bar every change meets: `.claude/rules/quality-bar.md`.

## Hard rules

- Every file under `src/` is `.ts` / `.tsx`. No `any`, no `@ts-ignore` /
  `@ts-expect-error`, no `as` to silence the compiler. Use `unknown` and narrow.
- `src/routeTree.gen.ts` is generated by the router plugin. Never edit it.
- Route files in `src/routes/` stay thin: path, search validation, guards,
  loader, `head()`, `headers()` and the container import. UI and logic live in
  `src/features/`.
- Secrets live in unprefixed env vars, read only inside server functions or
  `*.server.ts` files. Anything `VITE_*` ships to the browser.
- One `QueryClient` and one i18n instance per request, created in
  `getRouter()`. Never at module scope: it would leak one visitor's data into
  another visitor's HTML.
- Every public page renders its title, description, canonical and share tags
  on the server through `head()`. Private pages are `noindex`.
- A missing resource throws `notFound()` (HTTP 404); a renamed slug throws a
  301 `redirect()`. Never render "not found" text with a 200.
- No hardcoded user-facing strings: everything through the locale bundles, in
  both `ar` and `en`.
- A submit is single-flight: a second tap while one is in flight does nothing.
- Never test against the live site ({{LIVE_HOST}}). Use local mocks or UAT
  ({{UAT_HOST}}).
- Never touch deploy config (`.github/`, `deploy/`, `server/`, the `build`
  script) or `.env*` files.
- One branch per task from `origin/{{DEFAULT_BRANCH}}`. Ask before every
  commit and push. Never open a PR, never merge, never push to
  {{PROTECTED_BRANCHES}}.

Plugin hooks enforce these (config: `.claude/frontend-kit.json`).

## Layout

```
src/
├── router.tsx          getRouter(): per-request QueryClient + i18n, router context, defaults, SSR Query integration
├── start.ts            (optional) createStart: request middleware (language cookie, security headers)
├── routeTree.gen.ts    generated, never edited
├── routes/             thin route files only (file-based routing)
│   ├── __root.tsx      the document: <html lang dir>, <HeadContent/>, <Scripts/>, site-wide head, root notFound/error
│   ├── _site.tsx       pathless layout: header + footer + <Outlet/>
│   ├── _site/…         public pages
│   ├── _account.tsx    pathless guard (beforeLoad → redirect), noindex
│   └── sitemap[.]xml.ts, robots[.]txt.ts   server routes
├── features/
│   ├── website/<feature>/   index.tsx container, use-<feature>-page.ts, queries/, server/, components/, pages/, locales/
│   ├── auth/
│   └── fallback/            not-found, route-error
└── shared/                  api/, server/, lib/seo/, lib/i18n/, constants/ (endpoints, qk), components/,
                             hooks/, store/, utils/, types/, locales/, style/, assets/, env.ts
```

- **Containers render, hooks think.** A container (`index.tsx`) is JSX plus
  one `use-<page>-page.ts` call. Page hooks read the route with
  `getRouteApi('<route id>')` (no import cycle with the route file).
- **The feature root is the main page**; every other page owns a folder under
  `pages/`; a wizard's steps own folders under `steps/`.
- **A file lives in the deepest folder that contains every importer.** Promote
  to `src/shared/` on the second feature, never before.
- **Imports go up, never sideways.** Relative inside a feature, `@/…` across.
  kebab-case files, `index.tsx` for every container, no barrels.

## SSR and data, in short

- Content that must be in the first HTML (main content, title, existence,
  redirects) is awaited in the loader through the shared `queryOptions`; the
  component reads it with `useSuspenseQuery` (no second request).
- Secondary content streams: start the query without awaiting, render it in
  `<Suspense>` with a skeleton of the final size.
- Query keys come from `qk` (`src/shared/constants/query-keys.ts`); endpoints
  from `src/shared/constants/api.ts`.
- Mutation toasts come from one place (the `MutationCache` handlers); read
  errors go to the route `errorComponent` or the section's inline error.
- Language comes from a cookie, is resolved on the server, and the same value
  hydrates on the client — `<html lang dir>` never flips after load.
- Details: `.claude/rules/` `routing-ssr`, `data-loading`, `api-layer`, `seo-share`, `performance`.

## How the user talks

Often mixed languages and typos. Read intent, not spelling.

| They write                                  | They mean                                                         |
| ------------------------------------------- | ----------------------------------------------------------------- |
| `commit`, `commit push`, `yes commit push`  | Approval to commit **and** push the current task branch           |
| `continue`, `contine`                       | Resume the last unfinished step; don't restart or re-ask          |
| `all`, `check all`, `other pages`           | Every occurrence repo-wide, proven by a final grep                |
| `link pr`, `link`                           | Print the compare link + PR description                           |
| `why …?`, `explain`                         | Answer only, no edits                                             |
| `fast`                                      | Shortest correct path; the gates still run                        |
| a Figma link                                | Match it exactly (`figma-match`)                                  |

Scope rules from their corrections: `.claude/rules/scope.md`.

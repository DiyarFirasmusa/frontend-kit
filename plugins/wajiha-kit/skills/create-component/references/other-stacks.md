# A component, when the project has none to follow

- **React without TanStack Router:** a function component, typed props, callbacks out, the installed router's link.
- **Vue:** a single-file component with `<script setup>`, `defineProps` and `defineEmits`.
- **Svelte 5:** `$props()` and callback props. Older Svelte: `export let` and events.
- **Angular:** a standalone component with `input()` and `output()`, the signal and change-detection style of that major.
- **No framework (no UI library in `package.json`):** never JSX: a function that returns or mounts an element, text set with `textContent`, and a way to remove listeners.

Check the installed major before using its syntax.
